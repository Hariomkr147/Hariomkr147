<br>

Transforms educational documents into structured, source-grounded Teacher Knowledge Packages, including lesson plans, classroom activities, assessments, and misconception analysis.

| Aspect | Detail |
|---|---|
| **Stack** | FastAPI, React, Vite, SQLite, Docker, Gemini / Groq / OpenRouter |

| **Security** | Origin-tagged content with two-pass grounding and hallucination checks |
| **Impact** | Converts a chapter upload into a teacher-ready package in minutes |
| **Repository** | [github.com/Hariomkr147/Gyantra](https://github.com/Hariomkr147/Gyantra) |

Built as a fixed, auditable pipeline instead of a general-purpose agent framework so each stage can fail gracefully while critical checks still block bad outputs.
